# 📚 Smart Study Planner

A modern web-based study planner built with **HTML, CSS, and JavaScript**. Manage academic tasks efficiently with task management, calendar view, progress tracking, and smart reminders.

---

## 🌟 Features

### Core

* **Task Management** – Add, edit, delete tasks
* **Task Details** – Title, subject, due date, description, priority
* **Status Tracking** – Mark as completed/pending
* **Local Storage** – Data saved automatically

### UI

* Multiple views: **Tasks, Calendar, Statistics**
* Responsive design for desktop & mobile
* Clean, modern UI with smooth animations
* Dark/Light theme support

### Advanced

* Search & filter tasks by subject, status, or priority
* Calendar view for deadlines
* Progress & statistics dashboard
* Smart reminders for upcoming/overdue tasks

---

## 🚀 Getting Started

1. **Clone the repository**

   ```bash
   git clone <repo-url>
   cd smart-study-planner
   ```
2. **Open in browser**

   * Open `index.html` directly, or
   * Run a local server (`python -m http.server 8000`)

---

## 📱 How to Use

* **Add Tasks** → Fill form & click "Add Task"
* **Manage Tasks** → Edit, delete, or mark complete
* **Switch Views** → Tasks / Calendar / Statistics
* **Filter & Search** → Quickly find tasks
* **Reminders** → Notifications for deadlines & overdue tasks

---

## 🎨 Customization

* **Subjects** – Edit `<option>` in `index.html`
* **Themes** – Update CSS variables in `styles.css`
* **Priorities** – Adjust logic & styles in `script.js`
